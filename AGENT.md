# AGENT.md

**This file is intentionally a pointer, not a rulebook.** Its former contents —
the architectural directives, the "no God components" rule, the Zustand-only
state rule, the Tailwind/styled-components prohibition, the URL-length guard,
and the monologue-mode constraint — now live in `CLAUDE.md` §6. Keeping them
here too would mean the same rule existing in two places, drifting apart, with
nothing to say which copy is the lie.

All agents working in this repository follow **`CLAUDE.md`**, and read its
companions in the order that file's §0 sets out: `CLAUDE.md` →
`ARCHITECTURE.md` → `MEMORY.md` → `PROGRESS.md` → `TASKS.md` → `README.md`.

Do not add rules to this file. Add them to `CLAUDE.md` §6.
